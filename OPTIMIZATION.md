## 6. Splash Screen для новых пользователей

### Реализация
Добавлен splash screen, который показывается только при первом посещении сайта.

### Технические детали

#### Хранение состояния
- **Технология**: localStorage (выбран как наиболее надежный вариант)
- **Ключ**: `katushki_splash_shown`
- **Значение**: `'true'` после первого показа

#### Почему localStorage вместо cookies?
- **Надежность**: Не зависит от настроек браузера
- **Простота**: Не требует серверной обработки
- **Производительность**: Работает полностью на клиенте

#### Структура кода
```javascript
(function() {
    const SPLASH_VISITED_KEY = 'katushki_splash_shown';
    const SPLASH_DURATION = 2000; // 2 секунды

    function isFirstVisit() {
        return !localStorage.getItem(SPLASH_VISITED_KEY);
    }

    function showSplashScreen() {
        // Создание и показ splash screen
    }
})();
```

#### CSS Анимации
- **Появление**: `opacity: 0 → 1` с `scale(0.9) → scale(1)`
- **Исчезновение**: Плавное скрытие с задержкой
- **Длительность**: 0.3 секунды на анимацию

### UX особенности
- **Белый фон**: Чистый, минималистичный дизайн
- **Центрированный текст**: "You are welcome titles.." в верхнем регистре
- **Блокировка скролла**: `overflow: hidden` во время показа
- **Адаптивность**: Размер шрифта уменьшается на мобильных устройствах
