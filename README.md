# Катушки MVP

Минимально жизнеспособная версия проекта "Катушки" - сайт-визитка с лендингом товаров и переадресацией на Ярмарку мастеров.

## Структура проекта

```
katushki_mvp/
├── server.js          # Express сервер
├── package.json       # Зависимости проекта
├── views/             # EJS шаблоны
│   └── index.ejs     # Главная страница
├── public/            # Статические файлы
│   ├── styles.css    # Стилизация
│   └── script.js     # Клиентский JavaScript
├── tech.txt          # Техническое задание
└── README.md         # Документация
```

## Функциональность MVP

✅ **Сайт-визитка**
- Главная страница с приветственной секцией
- Раздел "О нас"
- Контактная информация

✅ **Лендинг / Разделы с товарами**
- Секция с каталогом товаров
- Карточки товаров с описанием и ценой
- Адаптивный дизайн
- Товары рендерятся на сервере через EJS

✅ **Покупки и переадресация**
- Кнопка "Купить" на каждом товаре
- Переадресация на Ярмарку мастеров с поиском товара
- Серверный роут `/buy/:productId` для обработки покупок

✅ **API endpoints**
- `GET /api/products` - получить все товары
- `GET /api/products/:id` - получить конкретный товар

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер:
   ```bash
   npm start
   ```
   
   Или в режиме разработки с автоперезагрузкой:
   ```bash
   npm run dev
   ```

3. Откройте в браузере:
   ```
   http://localhost:3000
   ```
